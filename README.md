# 众包式AI内容核查互动实验：Study 4

- 条件：资深核查贡献者
- 研究情境：居家收纳技巧
- 线上入口：https://chaoyifan.github.io/crowdcheck-s4-senior-contributors/

## 实验流程

参与者进入仿微博发布页，编辑并发布预置的居家收纳文案，选择内容声明，然后查看帖子结果。首次未选择“内容由AI生成”的参与者会看到本仓库对应的固定条件；首次选择AI声明者不进入条件比较。发布后可以通过“···—编辑动态”补充或撤销AI内容声明。

## Study 4操纵

控制组不显示社区附注。两个公开附注组使用相同的附注文本、30名评价者和24名“有帮助”评价，只改变评价者身份：普通社区贡献者，或资深核查贡献者。

附注中的来源信息使用易懂的中文直接呈现，不使用“历史可靠性70%/90%”等可能难以理解的统计表述。

## 数据接口

页面记录研究编号、固定条件、参与者编号、首次声明、补充声明、编辑操作、文案和事件时间戳，写入独立的 crowdchecking-study4-* localStorage 键，并向父页面发送 crowdchecking-study4-update 与通用完成消息。正式收数仍需由见数平台或研究服务器保存消息；GitHub Pages本身不提供集中式数据库。

## 使用边界

这是去品牌化的互动式仿真平台，不是真实微博，也不会真实发布内容或产生真实声誉后果。请勿输入真实姓名、联系方式、账号、住址等个人信息。
